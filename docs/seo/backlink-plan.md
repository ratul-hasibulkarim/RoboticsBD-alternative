# Backlink plan (earned links only)

No paid links, no PBNs, no comment or forum spam.

1. **University labs (BUET, DU, KUET, RUET, NSU, BRAC)** — offer a free "parts list → cheapest local source" page per course
   kit (e.g. EEE 2xx lab kits). Lab pages link to it because it saves students money.
2. **GitHub READMEs** — open-source a small `voltfind-bom` CLI that prices a KiCad BOM via our public API. Projects that use it link back.
3. **Hobbyist communities** — the team answers questions in r/AskElectronics and BD maker Facebook groups *as people*,
   linking only when a VoltFind page actually answers the question (comparison, price history). Follow each community's self-promotion rules.
4. **Data stories** — publish quarterly "BD component price index" posts from `price_daily` (e.g. ESP32 price in Dhaka vs import).
   Pitch them to BD tech media.
5. **Shop partners** — BD shops that submit feeds get a "Listed on VoltFind" badge they may choose to show.
6. **Manufacturer / distributor reference pages** — request listing as a price-comparison resource where programmes exist.
